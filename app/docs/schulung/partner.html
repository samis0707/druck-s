Partner-API: Aufträge einliefern und verfolgen

dmp druckraum · https://druck-s.de/api/partner · JSON · Zugang nach Vereinbarung
Online-Doku

Authentifizierung

Authorization: Bearer dmp_<64 hex>
Content-Type: application/json

Key und Webhook-Secret (whsec_…) werden einmal ausgegeben. Fehlt der Key, ist er falsch oder der Partner gesperrt → 401.

Endpunkte

AufrufZweck
POST /requestsAuftrag anlegen – idempotent über partnerRef (201 neu, 200 vorhanden)
GET /requests/{ref}Status abrufen (nur eigene)
POST /requests/{ref}/cancelZurückziehen, nur aus RECEIVED / IN_REVIEW

Auftrag anlegen – Pflichtfelder

{ "partnerRef": "bestellung-2026-0042",                         // 1–120 Zeichen A–Z a–z 0–9 . _ : -
  "customer": { "email": "…", "name": "…", "organisation": "…" },
  "product":  { "hint": "poster", "label": "Plakat A2", "widthMm": 420, "heightMm": 594, "bleedMm": 3, "sides": 1 },
  "quantity": 10, "wishDate": "2026-11-20",                       // YYYY-MM-DD oder null
  "delivery": { "mode": "abholung", "address": null },            // lieferung → address Pflicht
  "file": { "url": "https://…", "name": "plakat.pdf", "mime": "application/pdf", "size": 2048, "sha256": "…" },
  "source": { "system": "beispiel-partner" } }

file.url: HTTPS, Port 443, Host freigegeben; Größe und SHA-256 müssen exakt passen, höchstens 100 MB. Antwort: { "request": { id, number, status, partnerRef, createdAt, trackingNumber, specialDeliveryDate } }

Statusmodell

RECEIVEDeingegangen, Nummer vergeben
IN_REVIEWDruckerei prüft
WAITING_APPROVALAuftragsbestätigung an den Kunden
IN_PROGRESSper Code freigegeben, Produktion
SHIPPEDversendet; trackingNumber oder specialDeliveryDate
WITHDRAWNzurückgezogen (Endzustand)

Webhook status_changed

POST <webhook_url>
x-druck-s-timestamp: 1762596000
x-druck-s-signature: v1=HMAC-SHA256(secret, ts + "." + rawBody)
x-druck-s-delivery: 42
  • Zeitstempel höchstens 5 Minuten alt; Signatur über den rohen Body prüfen, zeitkonstant vergleichen.
  • Mit 2xx antworten. Sonst bis zu 10 Wiederholungen mit Backoff; 400/410/422 gelten als endgültig.
  • Über x-druck-s-delivery entdoppeln.

Fehlercodes — Antwort { error, code, details? }

400invalid_json · invalid_body (details listet alle Feldfehler) · file_host_not_allowed
401unauthorized – Key fehlt/falsch oder Partner gesperrt
404not_found – partnerRef unbekannt oder fremd
409not_withdrawable – Zurückziehen nach IN_REVIEW
413body_too_large – JSON größer als 64 KB
422file_unavailable · file_size_mismatch · file_sha256_mismatch · customer_disabled
429rate_limited – Retry-After beachten
500internal_error – gleichen Aufruf wiederholen (idempotent)
