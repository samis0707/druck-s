1

Daten eingeben

  1. Link öffnen, den Sie von der Druckerei bekommen haben. Mit Kundenkonto: Konto → Meine Vorlagen → Ausfüllen.
  2. Einzeln eingeben: Felder ausfüllen (Stern = Pflicht). Rechts sehen Sie sofort die Vorschau. Für den nächsten Eintrag + Weitere hinzufügen.
  3. Tabelle hochladen für viele Einträge: Beispieltabelle (Excel) laden oder Beispieltabelle (CSV) laden, Daten eintragen, Datei hineinziehen, Zuordnung bestätigen und übernehmen.
2

Prüfen

Weiter: Prüfen klicken. Jeder Eintrag hat ein Symbol:

  • Alles in Ordnung: druckbar.
  • Hinweis: druckbar, z. B. mit kleinerer Schrift.
  • Bitte prüfen: Zum Feld klicken und korrigieren.

Mit den Pfeilen blättern Sie durch die Vorschau.

3

Absenden

  1. Weiter: Absenden. Auflage eintragen, Für alle übernehmen.
  2. Name und E-Mail angeben, Weiter zur Bestätigung.
  3. 6-stelligen Code aus der E-Mail eintippen, Bestätigen und absenden.
Erst mit dem Code geht der Auftrag ein. Der Code gilt nur wenige Minuten. Kein Code da? Spam-Ordner prüfen, Code erneut senden.

Datenschutz in Kürze

  • Ihre Eingaben werden zwischengespeichert und spätestens 24 Stunden nach der letzten Änderung automatisch gelöscht. Sofort löschen: Meine Eingaben jetzt löschen.
  • Nach dem Absenden löscht unser Server Ihre Eingaben.
  • Tabellen bis 10 MB, höchstens 2.000 Einträge je Auftrag.
